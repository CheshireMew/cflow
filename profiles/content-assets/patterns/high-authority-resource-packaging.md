# 高权威资源包装模板

## 资产卡片

资产名称：高权威资源包装模板

资产类型：可迁移模式 / 短内容生产资产 / 包装与传播资产

适用场景：

- 包装一段高价值视频、访谈、备忘录、演讲、文章、清单或资料。
- 目标动作是观看、收藏、保存、转发或稍后学习；具体 CTA 要按资源时效性判断。
- 素材本身具备强权威人物、罕见资源、浓缩经验、可信数字或历史节点。

核心机制：

把资源包装成“低成本获得高权威智慧”的机会：

```text
顶级人物 / 权威背书
+
人生或财富结果证明
+
几十年智慧压缩成几十分钟
+
观看 / 收藏 / 保存 CTA
```

它真正卖的不是观点，而是读者可以用很低的时间成本，获得顶级人物一生或多年经验浓缩后的智慧。

CTA 不是固定写“收藏”。长期参考型资源更适合收藏/保存；IPO roadshow、发布会、财报、政策窗口、市场窗口等时效性资源，更适合号召现在观看或先看完。

## 证据样本

样本 1：

```text
霍华德·马克斯写备忘录时，沃伦·巴菲特会放下手头的一切去阅读。

马克斯是困境资产和市场周期方面的专家。

他将78年的投资智慧浓缩成了一个60分钟的视频。

收藏这段珍贵影像。
```

有效动作：

- “巴菲特会放下手头的一切去阅读”提供顶级背书。
- “困境资产和市场周期方面的专家”补权威领域。
- “78年智慧 -> 60分钟视频”制造知识套利感。
- “收藏这段珍贵影像”给低摩擦动作。

样本 2：

```text
瑞·达利欧把自己公寓里的一个初创项目，做成了一个价值 1500 亿美元的商业帝国。

大多数人花一辈子都在试图理解市场。

而达利欧把 75 年的投资智慧，浓缩成了 42 分钟。

把这段视频收藏起来。
```

有效动作：

- “公寓里的初创项目 -> 1500亿美元商业帝国”提供结果证明。
- “大多数人花一辈子”抬高问题难度。
- “75年智慧 -> 42分钟”压低获取成本。
- “收藏起来”匹配资源型内容的自然动作。

样本 3：

```text
1999 年，巴菲特解释了为什么大多数人永远无法致富。

他证明了你此刻身上就携带着一项价值 50 万美元的资产。

在你错过它之前，保存这段罕见的视频。
```

有效动作：

- “1999年”制造历史节点和罕见感。
- “为什么大多数人永远无法致富”直接触发利益与恐惧。
- “你身上就携带着一项价值50万美元的资产”制造强 open loop。
- “在你错过它之前”强化损失感。

## 可迁移模板

```text
[顶级人物 / 权威背书] 曾经 [做出一个反常或高信号动作]。

他/她在 [领域] 里证明过自己：[结果、身份、成就或关键判断]。

他/她把 [几十年经验 / 一生方法 / 罕见判断] 浓缩成了 [很短时间 / 一个视频 / 一篇文章 / 一张清单]。

在你错过它之前，先保存下来。
```

更短版本：

```text
[权威人物] 用 [多年经验 / 关键判断 / 罕见经历] 证明了 [读者关心的大问题]。

这段 [视频 / 文章 / 清单 / 访谈] 把它压缩成了 [低时间成本]。

先收藏，别等需要时找不到。
```

## CTA 判断

先判断资源类型：

- **长期参考型**：经典演讲、历史备忘录、常青方法论、教程、清单。主 CTA 用收藏、保存、留着看。
- **时效窗口型**：IPO roadshow、发布会、财报、政策解读、市场窗口、限时事件。主 CTA 用现在看、先看完、别只看二手解读、趁窗口还在过一遍。

收藏和观看可以同时出现，但只能有一个主动作。时效性强时，观看是主动作，收藏只能作为次要动作。

## 使用条件

必须至少具备其中两项：

- 权威人物足够强，读者听到名字就愿意停一下。
- 资源本身稀缺，例如罕见影像、老演讲、内部备忘录、经典采访、浓缩课程。
- 数字可信且具体，例如年份、资产规模、从业年限、视频时长、成果数字。
- 读者有明确的学习焦虑、财富焦虑、认知差距或错过恐惧。

## 不可复制条件

不要直接复制这些部分：

- 作者身份、粉丝基础、渠道分发优势。
- 特定投资大师的人名光环。
- 没有来源支撑的年份、金额、身份和结论。
- 题材红利带来的天然吸引力。

人物不够强、素材不稀缺、数字没来源时，这套写法会显得廉价或标题党。

## 常见失效

- 只堆名人，但没有说明资源为什么稀缺。
- 只说“值得收藏”，但没有给时间压缩或知识套利感。
- 数字太虚，例如“多年经验”“很多财富”“顶级智慧”。
- CTA 和资源不匹配，例如时效型 roadshow 只让人收藏、不提醒现在看，或长期参考资料硬要制造即时焦虑。
- open loop 过重但视频或资料不能兑现，容易损害信任。

## 归属 skill

- `$cflow-package`：负责标题、hook、观看/保存型 CTA、资源包装强度。
- `$cflow-viral`：负责收藏、转发、截图、复述和错过恐惧机制。
- `$cflow-shortform`：负责把模板压成超短、短内容或短脚本正文。

## 下一次使用方式

当用户提供一段高价值资源、视频、访谈、演讲或文章时，可以调用这个资产：

```text
使用“高权威资源包装模板”，把这个素材包装成资源型短内容，并按时效性选择观看或收藏 CTA。
```

生产时先检查：

1. 谁是权威人物？
2. 他/她有什么可验证结果？
3. 这份资源稀缺在哪里？
4. 能否形成“多年智慧 -> 低时间成本”的压缩感？
5. 这是长期参考型还是时效窗口型？
6. CTA 应该是观看、收藏、保存、转发、预约还是私信？
