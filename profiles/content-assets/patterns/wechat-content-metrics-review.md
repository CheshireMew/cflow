# 公众号内容指标复盘

## 资产卡片

资产名称：公众号内容指标复盘

资产类型：可迁移模式 / 数据复盘资产 / 账号诊断辅助资产

来源：`$cflow-review` 对一篇外部内容方法论文章的机制复盘。该资产只沉淀指标解释方式，不把原文给出的具体百分比作为 CFlow 通用标准。

## 核心机制

阅读量不是内容质量本身。

公众号和长文复盘更适合把指标归一到读者行为：

```text
常读用户数 -> 账号关系资产 / 复访
完读率 -> retention / 正文兑现
赞阅比 -> 轻互动 / 认可
转阅比 -> 传播价值 / 读者愿意替自己表达
评论和私信 -> 误读、共鸣、异议、转化线索
关注转化 -> 单条内容能否承接成账号关系
```

具体阈值只在该账号、该平台、该阶段内有意义。复盘时先看相对趋势、同栏目比较和异常值，不把别人的标准写成自己的结论。

## 指标解释

### 常读用户数

看账号和读者之间是否形成关系。

它回答：

```text
读者是否反复回来？
他们回来是看信息，还是看这个账号的判断？
爆款之后有没有转成复访？
```

常读弱但单条阅读高，可能是内容吸引力强、账号关系资产弱。

### 完读率

看内容有没有持续兑现。

它回答：

```text
开头承诺是否被正文持续兑现？
中段是否掉张力？
长文是不是靠信息密度变长，而不是靠解释撑长？
```

完读低不一定是文章太长，也可能是角度、结构或中段刷新失败。

### 赞阅比

看轻认可。

它回答：

```text
读者是否觉得这条内容值得顺手支持？
是否有清楚判断、情绪共鸣或实用价值？
```

赞高转低时，内容可能被认可但不够有分享动机。

### 转阅比

看传播价值。

它回答：

```text
读者愿不愿意把它发给别人？
转发时读者在表达身份、立场、实用价值还是情绪？
内容里有没有截图点、复述句或可带走结构？
```

转发强的内容优先交给 `$cflow-viral` 和 `$cflow-review` 沉淀传播单元。

## 复盘口径

```text
内容目标：reach / retention / engagement / share / conversion / trust
原文或关键片段：
发布环境：
同栏目基准：
阅读量：
常读用户数 / 关注转化：
完读率：
点赞 / 赞阅比：
转发 / 转阅比：
评论 / 私信：
异常指标：
内容本体假设：
下一轮实验：
```

缺少原文时，只能判断指标分布和候选假设，不能断言“内容为什么好”。

## 诊断地图

- 高阅读、低常读：爆款可能没有承接成账号关系。
- 高完读、低转发：内容能读完，但缺少可替读者表达的传播单元。
- 高转发、低关注：传播点强，但作者识别、主页承接或后续栏目弱。
- 高赞、低评论：认可够，但讨论入口弱。
- 低阅读、高转化：题可能窄但商业价值高，值得换包装重复。
- 高阅读、低完读：首屏或标题有效，但正文没有兑现。

## 不可复制条件

- 原文中的具体百分比阈值。
- 原账号粉丝量、历史信任和公众号生态位置。
- 特定时间窗口和平台分发环境。

这些可以作为本地 benchmark 的例子，不能作为通用达标线。

## 调用方式

当用户提供公众号或长文后台数据时，可以调用这个资产：

```text
用“公众号内容指标复盘”先把指标归一到读者行为，再结合原文判断内容本体。不要用阅读量单独定性，也不要套用外部账号的固定阈值。
```

是否需要交给 `$cflow-maintain`：否。当前是生产资产，不改变 CFlow 长期流程、边界或路由。
