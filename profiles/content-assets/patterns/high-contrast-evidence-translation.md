# 高反差证据速译模式

## 资产卡片

资产名称：高反差证据速译模式

资产类型：可迁移模式 / 短文案生产资产 / 包装与角度资产

来源：`$cflow-review` 对一条 X 内容的复盘。样本把一篇关于隔夜收益和日内收益差异的论文，压成“收盘买入、开盘卖出”和“开盘买入、收盘卖出”的强对比，并带来异常高浏览和明显关注增长。

## 核心机制

把复杂发现翻译成读者能立刻复述的强对比。

结构：

```text
高反差发现
-> 情绪定性
-> A / B 对比
-> 极端证据
-> 读者相关落点
```

这个模式不依赖“论文”本身。论文只是证据来源之一。真正可迁移的是：

```text
复杂材料里存在两个动作、规则、选择、结果或立场。
两者结果差极大。
读者一眼能看懂差异，并能转述给别人。
```

## 适用材料

- 论文、研究、报告或白皮书。
- 市场数据、投资回测、财报、行业指标。
- 产品实验、AI 工具测试、平台规则变化。
- 政策变化、制度差异、组织操作失误。
- 用户行为反差、历史案例、行业荒诞事件。

## 使用方式

先找对比，不先写背景。

```text
A 做了什么。
B 做了什么。
A 和 B 的结果差是多少。
这个结果为什么和读者有关。
```

可用证据：

- 极端数字。
- 图表走势。
- 前后对比。
- 截图原文。
- 实验结果。
- 真实案例。
- 用户能看懂的动作差。

## 判断标准

适合使用：

```text
能压成 A / B 对比。
证据差足够大。
读者不需要专业背景也能懂。
有图表、数字、原话或结果支撑。
能落到读者熟悉的场景、身份或利益。
```

不适合使用：

```text
只有作者情绪，没有证据。
只有复杂背景，没有清楚对比。
数字很大但读者不知道意味着什么。
需要大量解释才看懂。
结论依赖特定作者、平台、时机或私有资源。
```

## 写作提醒

- 情绪定性只用一句，不能替代证据。
- 不要把“离谱”“震惊”“阴谋”当成机制本身。
- 极端证据要尽量前置。
- 读者相关落点要具体，不要写成空泛行业意义。
- 如果证据边界不清，保留来源姿态，例如“论文作者认为”“数据里显示”。

## 下一次使用

遇到强材料时先问：

```text
这里的 A / B 是什么？
结果差是否足够极端？
有没有图表、数字、原话或案例支撑？
读者能不能一句话复述？
它和读者的投资、工作、工具使用、判断或身份有什么关系？
```
