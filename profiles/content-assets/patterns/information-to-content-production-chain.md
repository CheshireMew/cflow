# 信息到内容生产链

## 资产卡片

资产名称：信息到内容生产链

资产类型：可迁移模式 / 内容生产流程资产 / 质检资产

来源：`$cflow-review` 对一篇外部内容方法论文章的机制复盘。该资产沉淀的是“信息如何被加工成内容”的流程，不代表对原文人物、数据、书籍和平台经验做过事实核查。

## 核心机制

信息不是内容，转述也不是内容。

一条信息要变成可发布内容，至少经过三次加工：

```text
获取信息
->
找到角度
->
完成创作兑现
```

对应的读者价值是：

```text
我知道发生了什么
->
我用新的方式理解它
->
我获得一个能记住、相信、复述或行动的 payoff
```

如果只停在第一步，输出通常只是搬运、翻译、摘要或说明书。它可能有资料价值，但还没有形成内容价值。

## 三层加工

### 1. 信息层：原料是否值得处理

先判断信息是什么：

- 新事件 / 新工具 / 新政策 / 新趋势
- 用户经历 / 项目素材 / 读者反馈
- 对标样本 / 研究资料 / 案例线索
- 作者观察 / 日常场景 / 反常识经验

信息层只回答：

```text
发生了什么？
有什么具体素材？
哪些事实需要核查？
读者是否已经知道这件事？
```

这一步归 `$cflow-topic`、`$cflow-research`、`$cflow-review` 或 `$cflow-interview`。

### 2. 角度层：为什么值得看

角度层要把原料变成读者进入理由。

检查：

- 它和读者原有预期哪里相反？
- 读者正在付出什么代价？
- 哪类人会因此重新判断？
- 这件事暴露了什么更大的机制？
- 如果所有人都会这么写，另一个合理但不显眼的入口是什么？

这一步归 `$cflow-angle` 和 `$cflow-package`。如果没有角度，不能直接把资料铺成正文。

### 3. 创作层：是否兑现承诺

创作层要完成阅读体验，而不是把角度解释一遍。

检查：

- 开头是否直接进入事实、场景、判断或冲突？
- 正文有没有递进，而不是资料并排？
- 是否有故事、场景、例子、对比、数据或动作让读者相信？
- 每一段是否提供新信息、新情绪、新推理或新行动？
- 结尾是否兑现开头承诺，并留下记忆点或自然动作？

这一步归 `$cflow-draft`、`$cflow-case`、`$cflow-edit` 和 `$cflow-check`。

## 快速质检

用下面问题判断它是不是还停在信息搬运：

```text
删掉来源、热点或工具名后，这条内容还剩下什么作者判断？
读者看完只是知道一件事，还是获得了新理解？
正文是否只是按原信息顺序复述？
有没有一个能复述给别人的句子、场景或结构？
这条内容能沉淀账号关系资产，还是只消耗一次信息差？
```

命中三项以上，先回到 `$cflow-angle` 或 `$cflow-draft` 重组，不要只修标题。

## 可迁移模板

```text
原始信息：
目标读者：
读者已经知道什么：
显而易见写法：
新的理解入口：
核心主张：
支撑素材：
故事 / 场景 / 案例：
正文推进顺序：
payoff：
后续可沉淀资产：
```

## 不可复制条件

- 原作者的行业经验、粉丝基础和内部数据。
- 特定平台的实时指标阈值。
- 原文中的具体工具、书籍、人物和公司背景。
- 作者个人口吻和经历。

这些只能作为启发或例子，不能直接写进用户内容。

## 调用方式

当用户提供一条资讯、热点、转述材料或行业新闻，并希望写成内容时，可以调用这个资产：

```text
用“信息到内容生产链”判断这份材料现在停在哪一层：信息、角度还是创作。先补缺失层，再决定交给 cflow-topic、cflow-angle、cflow-draft 或 cflow-check。
```

是否需要交给 `$cflow-maintain`：否。当前是生产资产，不改变 CFlow 长期流程、边界或路由。
