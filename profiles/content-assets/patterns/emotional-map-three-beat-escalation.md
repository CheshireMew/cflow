# 情绪地图三番升番

## 资产卡片

资产名称：情绪地图三番升番

资产类型：可迁移模式 / 长文结构资产 / 脚本节奏资产 / 编辑诊断资产

来源：`$cflow-review` 对一篇外部内容方法论文章的机制复盘。该资产沉淀节奏和情绪推进方法，不沉淀原文里的具体节目、书籍或案例事实。

## 核心机制

好内容不是把信息平均铺开，而是设计读者的情绪路线。

三番升番的目标不是“更夸张”，而是让每一次推进都比上一次多给读者一个新东西：

```text
第一番：建立兴趣
第二番：升级冲突或理解
第三番：给出超预期 payoff
```

如果每一段都只是补充说明，读者会觉得正确但平。如果每一番都只提高音量，读者会觉得吵。升番必须来自新信息、新场景、新代价、新反差或新动作。

## 情绪地图

先画内容的情绪轨迹：

```text
开头：好奇 / 被点名 / 被冒犯 / 被看见
第一段推进：理解发生了什么
第二段推进：发现旧理解不够用
第三段推进：看到具体代价、反差或案例
收束：获得判断、方法、行动或记忆句
```

常见失败是全程只有一种情绪：

- 全程解释：像说明书。
- 全程兴奋：像硬广。
- 全程悲观：没有行动出口。
- 全程正确：没有记忆点。

## 三番结构

### 第一番：让读者进来

功能：

- 点名读者处境。
- 给出反常现象。
- 提供一个具体场景。
- 建立“这和我有关”的理由。

不要急着讲完整背景。

### 第二番：让读者意识到问题更深

功能：

- 揭示旧方法为什么失败。
- 补一个更具体的代价。
- 引入反例、异议或第二个场景。
- 把读者从“知道了”推到“原来是这样”。

这里要刷新张力，不能只复述第一番。

### 第三番：兑现记忆点

功能：

- 给出最强案例、最清楚判断或最可复述结构。
- 把前面的铺垫压成一句读者能带走的话。
- 给行动、收藏、转发、评论或复访一个自然理由。

第三番不是总结，而是 payoff。

## 诊断问题

```text
第一番是否足够具体，让读者愿意进来？
第二番是否真的升级，而不是重复解释？
第三番是否有超出预期的 payoff？
每一次升番靠的是新素材，还是只靠更强形容词？
情绪低谷之后有没有新的理解或行动出口？
删掉某一番后，内容是否几乎不变？
```

如果删掉任何一番都不影响内容，说明它只是填充。

## 可迁移模板

```text
主张：
目标读者：
当前情绪轨迹：
第一番：进入理由 / 场景 / 反常现象
第二番：升级冲突 / 隐藏代价 / 反例
第三番：最强案例 / 记忆句 / payoff
需要补的素材：
可能删掉的平铺段落：
结尾动作：
```

## 不可复制条件

- 原文提到的喜剧节目、具体作品和个人观看经验。
- 原作者的表达强度和行业语境。
- 需要表演语境才能成立的节奏设计。

这些只能作为节奏启发，不能硬搬到所有文章。

## 调用方式

当用户说“这篇太平”“读着没起伏”“信息都对但不好看”时，可以调用这个资产：

```text
用“情绪地图三番升番”标出当前内容的第一番、第二番、第三番。找出没有升级的段落，改成新场景、新代价、新反差或新 payoff。
```

是否需要交给 `$cflow-maintain`：否。当前是生产资产，不改变 CFlow 长期流程、边界或路由。
