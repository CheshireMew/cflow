# 营销转化系统

## 营销形态

### 硬广

适合高意向人群或明确转化场景。

特征：

- 产品、offer 或购买动作直接出现
- CTA 清晰
- 证据和异议处理密度高
- 不假装自己不是广告

风险：

- 对冷流量容易显得冒犯
- 欲望不足时会变成强推

### 软广

适合冷流量、内容平台、信任建设或品牌内容。

特征：

- 先服务读者问题
- 产品或 offer 后置
- 用故事、案例、方法或经验建立 desire
- CTA 可以更轻

风险：

- 太软会没有转化动作
- 只讲故事但没有 offer，会浪费营销目标

### Advertorial / Native Ad

适合需要像内容一样被阅读、但仍有明确转化目标的场景。

特征：

- 读起来像文章、案例或报道
- 结构服务转化
- 内容和 offer 之间有自然桥
- 标题和开头不应暴露得像低质量广告

### Direct Response

适合明确要成交、预约、领取、咨询或注册。

特征：

- 目标动作单一
- 使用 AIDA、PAS、故事销售或问题-机制-证明-行动
- 强调 proof、objection handling、urgency 和 CTA

## Funnel Stage

### 冷流量

读者还没有信任或强需求。

优先：

- 读者处境
- 问题命名
- 故事和案例
- 低摩擦 CTA
- lead magnet

避免：

- 过早要求购买
- 直接堆产品功能
- 需要太多信任的承诺

### 暖流量

读者知道问题，也开始相信作者或品牌。

优先：

- 机制解释
- 对比
- 案例
- 常见异议
- 中摩擦 CTA

### 高意向

读者已经接近行动。

优先：

- Offer 细节
- 价格或方案
- 风险逆转
- FAQ
- 强 CTA
- 购买、预约或咨询路径

## Offer 表达

一个 offer 至少回答：

```text
给谁：
解决什么问题：
交付什么结果：
为什么可信：
为什么现在行动：
下一步是什么：
```

弱 offer 气味：

- 只描述产品，不描述结果
- 只讲功能，不讲读者处境
- 没有可信证据
- 没有明确下一步
- 对所有人都适用
- 行动成本和读者信任阶段不匹配

## CTA 类型

### 低摩擦 CTA

适合冷流量和信任不足时：

- 收藏
- 评论关键词
- 私信领取
- 下载清单
- 查看案例
- 关注后续

### 中摩擦 CTA

适合暖流量：

- 填表
- 加入 waitlist
- 预约诊断
- 领取试用
- 观看 demo
- 加群或进社群

### 高摩擦 CTA

适合高意向：

- 购买
- 付费咨询
- 申请加入
- 签约
- 预约销售电话

CTA 规则：

- 一个内容通常只保留一个主要 CTA。
- CTA 强度必须匹配读者信任阶段。
- CTA 文案要说明动作后会发生什么。
- 不要用多个不同目标互相稀释。

## 转化桥

从内容到行动之间，通常需要一个或多个桥：

- 读者痛点被准确命名
- 失败解决方案被解释
- 机制被说明
- 证据被展示
- 异议被提前处理
- 结果被具体化
- 风险被降低
- 下一步被讲清楚

如果内容有价值但不转化，通常不是内容不够好，而是缺少转化桥。

## 常用结构

### PAS

```text
Problem
Agitate
Solution
Proof
Action
```

适合短广告、短视频广告、landing page 开头。

### AIDA

```text
Attention
Interest
Desire
Action
```

适合 sales copy、advertorial、长广告。

### 故事销售

```text
场景
压力
失败解决方案
转折
机制
结果
offer
CTA
```

适合软广、案例、创始人故事、社群或服务转化。

### 案例转化

```text
客户处境
阻碍
做了什么
结果
为什么有效
读者如何复制
CTA
```

适合 B2B、咨询、社群、课程、服务和工具。
