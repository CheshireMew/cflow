# 包装模式

## 包装资产

- 标题
- Hook
- 开头段
- 副标题
- CTA
- Caption
- Thread 第一条
- 短视频前三秒
- 平台专用版本

## 强张力来源

- 读者错误
- 隐藏代价
- 前后对比转变
- 反直觉区分
- 具体受众处境
- 决策取舍
- 具体结果
- 被经验挑战的常见认知

## Copywriting 机制

- **Mind the gap**：制造一个具体、未解决的张力，让读者必须继续看。Hook 不能只是总结内容。
- **Punch first**：第一句要能打断注意力。除非平台奖励上下文，否则不要软铺垫。
- **Slippery slope**：每句话都应该让下一句自然被读下去。不能推进的句子就删或改。
- **用标题筛选读者**：标题可以点名窄人群、身份、地点、状态、问题或欲望。无关读者不点进来是好事。
- **具体性强化强烈程度**：用具体门槛、场景、身份和素材承载强表达，不要只加形容词。
- **Open loop 先抓住人**：默认优先制造继续看的冲动；只有用户要求严谨包装或品牌安全时，才严格审查兑现边界。

## 标题和 Hook 策略标签

生成选项时，每个选项至少标注一个策略：

- **认知冲突**：打破读者已有判断。
- **好奇缺口**：点出未解释的信息差。
- **恐惧/损失**：命名读者正在付出的代价。
- **身份代入**：直接点名人群、处境、阶段或角色。
- **数字锚定**：用数量、时间、门槛、比例形成抓手。
- **结果承诺**：说明读者会得到的具体结果。
- **社会证明**：引用特定人群、案例、数据或可见反馈。
- **争议/挑衅**：挑战流行观点，把读者拖进判断。
- **场景/条件**：把内容放进具体使用场景。
- **行动号召**：直接要求下一步，通常配合 CTA。

策略标签不是装饰。标不出策略的选项，大概率只是同义改写。

## Hook 重做门槛

用户要求“更吸引人”“有点击欲”“反常识”“有技巧”，或反馈“平淡”“像提醒”“没有 hook”时，先承认当前问题属于包装策略失败，再换策略重做。

输出至少覆盖 3 种不同策略，优先从这些方向选：

- **认知冲突**：你以为第一步是 X，其实先做 Y。
- **损失规避**：不做这个动作，后面每次都在付代价。
- **身份差距**：新手直接做，老手会先做另一步。
- **信息差**：别人还在找入口，你已经能直接操作。
- **行动压力**：现在多做一步，后面省掉长期麻烦。

不要输出 5 个同义提醒句。每个候选都要能说明它为什么会让目标读者继续看或点击。

入口型链接包装示例：

```text
素材：用户提供注册链接、返佣、邀请码、风险提醒，并要求链接前置。
错误做法：补写原文没有的服务范围，或用“注册前先看看”这种弱提醒。
正确做法：先判断主 CTA 是注册链接或返佣入口；hook 用认知冲突、损失规避或身份差距制造点击理由；风险提醒后置压缩。
```

## 开头质量门槛

短视频或社交平台开头必须独立成立。不要假设读者已经看过标题、视觉资产或上下文。

好开头通常同时包含：

```text
话题：这条内容在说什么
Hook：为什么现在要听
行动理由：为什么读者现在应该继续看
```

前三秒不要只重复标题。开头应带来新信息、新张力或新场景。

## AIDA 销售包装

当内容有销售或转化目标时使用 AIDA：

```text
Attention：打断准确读者
Interest：描述熟悉处境或未解决问题
Desire：建立信念、转变、利益和情绪拉力
Action：欲望存在后再要求下一步
```

不要在读者还没有理由关心前就抛产品、价格或 CTA。价格必须出现时，把它放进结果或体验里，而不是裸折扣。

例外：渠道情报型、机会窗口型、限时入口型文案。它的关注理由就是入口、截止时间、资格和可操作链接本身，开头必须先给窗口变化和入口对象，不要为了 AIDA 把产品和 CTA 后置。

## 渠道情报型包装

适合限时入口、邀请码、注册链接、教程链接、福利活动、资格窗口、支付/出入金/工具机会。

包装目标不是“介绍产品”，而是制造“我现在知道一个快关门入口”的消息感。

强包装元素：

- 截止时间：明天 12:00、最后 24 小时、这次窗口。
- 稀缺入口：大陆护照可开、低门槛、还能申请、少数可用入口。
- 内行信息差：别人还在找渠道，你已经能直接操作。
- 利益点列表：充值、绑定、消费、福利、教程、邀请码。
- 直接 CTA：看完直接办、链接在下面、邀请码别填错。

保留：

- 短句。
- 符号列表。
- 群消息式粗糙感。
- 压迫感。
- 优越感和信息差。

避免：

- 改成产品介绍标题。
- 用长过渡句铺垫。
- 把列表利益点合并成长段落。
- 把 CTA 藏到最后才第一次出现。
- 用“值得看看”“可以了解一下”这种弱动作替代直接操作。

## Pressure Before Claims

包装产品、服务或说服型内容时，优先把强主张落到可感知素材上：

- 前后对比
- 截图或指标
- 具体客户场景
- 来自特定人群的 social proof
- 能回答异议的个人轶事
- 可见转变，而不是产品描述

如果素材不够，广告、短视频、小红书、viral 和限时活动场景仍先产出强版本。只有严肃论证、研究型内容、事实判断或用户主动要求时，才标出证据缺口。

## 推广和分享文案

当用户要为文章、newsletter、blog 或外部链接写推广文案时，包装目标不是复述全文，而是找到一个强、准、能让人点开的进入点。

- 不要摘要全文。推广文案只需要暴露最值得点开的张力、问题、判断或具体细节。
- 链接是自然下一步，不是硬贴附件。读者读完前文应知道为什么继续点开。
- 文案必须自洽。读者即使暂时不点链接，也应该知道这条内容的价值是什么。
- 默认基于原文素材放大，不另造新信息、数据、案例或结论；用户要求严谨包装时，再检查 hook 和原文支撑关系。
- 每个候选要使用不同进入点，例如一个从反常识进入，一个从具体场景进入，一个从读者损失进入；不要只是换同义词。
- 如果原文没有足够张力，先从读者损失、场景、反常识、身份或行动压力里找更锋利的进入点。只有用户要求严谨包装时，才把支撑缺口作为问题展开。

判断推广 hook 是否成立：

```text
这句话是否足够让目标读者想点开？
读者是否知道为什么要点开？
这句话是否只是摘要，而不是进入点？
删掉链接后，文案是否仍然有信息价值？
```

## 个人引流 CTA 包装

当内容适合接作者个人引流资产时，资产清单以 `$cflow-marketing` 的 `leadgen-profile.md` 为准。`cflow-package` 只负责把入口包装得自然、短、适合平台。

常用包装方式：

- **直接链接**：适合 Telegram、Substack、博客、教程、交易所注册链接可以直接出现的平台。
- **主页简介**：适合 X、视频号、小红书等不方便放链接或链接会影响阅读的平台。
- **评论关键词**：适合短视频、小红书、私域承接，例如“评论区打教程”。
- **私信关键词**：适合需要筛选意向或不想公开链接时。
- **置顶入口**：适合系列内容、长期资源或多个链接并存时。

包装纪律：

- 单篇内容默认只保留一个主引流动作。
- CTA 要接内容场景，不要机械写“欢迎关注/欢迎订阅”。
- 不方便放链接时，不要硬塞裸链，改成“入口在主页简介”“置顶里有”“私信我关键词”。
- 如果内容不适合引流，只在交付后轻提醒，不强行写进正文。

## 平台模式

### 小红书/RED

- 读者和利益要具体。
- 文案要方便扫读。
- 避免模糊的成长、效率、逆袭承诺。

### 短视频

- 从张力或场景开始。
- 用口语。
- 避免长铺垫。
- 一句话一个拍点。
- 高留存脚本要在观众离开前，用新细节、转折或 open loop 刷新注意力。

### LinkedIn

- 使用职业张力。
- 自信要匹配作者和平台语境。克制不是降温；锋利判断、明确立场和强结果仍然可以使用。
- 避免无功能假脆弱。强叙述、强反差和强判断可以保留。

### Twitter/X

- 压缩主张。
- 每条只推进一个想法。
- 第一条要制造好奇，但不能隐藏主题。

### Newsletter 或 Blog

- 优先耐用承诺和清晰范围。
- 避免和正文气质不匹配的社交平台式兴奋；如果内容目标是推广、招募或限时转化，可以保留更强的标题压力和 CTA。

## 变体规则

- 生成不同策略的选项，不要只换同义词。
- 保持主张有冲击力。
- 只有用户要求严谨、合规或品牌安全时，才检查事实和承诺边界。
- 具体性用来承载刺激感，而不是替代刺激感。
- 让最佳选项容易被选择。
- 区分 hook 质量和正文质量：弱 hook 会杀死强内容，强 hook 也救不了空内容。
