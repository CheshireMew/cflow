# 短内容系统

## 共享合同

短内容受 `$cflow` 的 `references/content-production-contract.md` 约束。本文件只维护短帖、短视频、thread 和平台短格式的应用规则。

## 短内容原则

- 一条只说一个点。
- 开头必须独立成立，不依赖标题、视觉资产或上下文。
- 先让读者知道“为什么现在要看”。
- 结尾不要强行升华，短内容可以停在判断、问题、行动或记忆点。
- 适合拆成系列时，不要硬塞进一条。
- 写给中文母语者时，先抓住注意力和行动欲。不要默认少营销腔；有转化目标时保留甚至强化有功能的销售语气。
- 段落保持清爽。短内容里一段太长，通常就是没剪干净。
- 短内容的呼吸感主要来自换行、短停顿、列表和自然停点。

## 常用结构

### 场景到判断

```text
具体场景
读者识别
判断
一句解释
结尾问题或行动
```

适合小红书、LinkedIn、朋友圈、短视频口播。

### 反常识到机制

```text
大家以为 X
但实际是 Y
为什么
一个例子
怎么用
```

适合观点短帖、X、LinkedIn、短视频。

### 问题到答案

```text
一个具体问题
直接答案
错误做法
正确做法
下一步
```

适合教学型短内容、私域、FAQ 式内容。

### 微故事到洞察

```text
一个短场景
转折
暴露的问题
洞察
可迁移一句话
```

适合有案例但篇幅不够展开时。

### 清单型

```text
对象或场景
3 到 7 个要点
使用条件
避坑提醒
```

适合小红书、LinkedIn、私域、图文。

### 渠道情报型

```text
截止时间
入口是什么
为什么稀缺
3 到 7 个强利益点
别人还在 X，你可以 Y
福利 / 邀请码 / 链接
直接操作
```

适合限时入口、资格窗口、开卡教程、福利活动、邀请码、注册链接、支付/出入金/工具机会。它要像短消息，不像产品说明。保留短句、符号、列表、紧迫感和扫读冲击。

### 对比型

```text
A 做法
B 做法
关键差异
适用场景
一句判断
```

适合解释误区、选择题、工具/方法比较。

### Thread 型

```text
第一条：主张 + 为什么值得看
中间：每条只推进一个子点
最后：总结、行动或资源
```

Thread 不是把长文切段。每条都要有推进功能。

## 平台差异

### 短视频

- 一句话一个拍点。
- 前三秒给场景、冲突或判断。
- 用口语，不写书面段落。
- 每 5 到 8 秒刷新一次信息：新细节、转折、例子、问题或画面。
- 结尾可以引导评论、私信或行动。默认优先完成内容目标。

### 小红书/RED

- 标题由 `$cflow-package` 处理，封面和配图由 `$cflow-image` 处理，正文要方便扫读。
- 读者处境要具体。
- 多用生活细节、步骤、清单、前后对比。
- 默认允许成长、效率、逆袭承诺，只要能制造点击或行动；用户要求严谨/品牌安全时再收窄。

### Twitter/X

- 单条要锋利，thread 要顺序推进。
- 不隐藏主题太久。
- 每条优先承载一个判断、情绪、利益或行动。
- 适合反常识、定义、对比、金句和短清单。

### LinkedIn

- 使用职业场景、决策张力、管理/团队/产品/行业语境。
- 克制只在用户要求职业可信度时使用。默认保留锋利判断和强立场。
- 用具体经历、判断或强表达建立停留和行动欲。

### 朋友圈 / 私域

- 私域可以重关系感，也可以重成交动作，按用户目标决定。
- 私域成交可以直接卖；如果用户要求关系感，再调整成真人对熟人说话。
- 可以更短、更直接、更像人话。
- CTA 要低摩擦，适合引发私聊或回复。

## 长文拆短

长文拆短时，先找短内容单元：

- 一个强判断
- 一个具体场景
- 一个反常识
- 一个案例
- 一个清单
- 一个问题
- 一个对比
- 一个读者异议

每个单元单独成条。不要把长文摘要当短内容。

## 短内容质量检查

- 是否只有一个单点？
- 首句/前三秒是否独立成立？
- 有没有具体场景或细节？
- 是否删掉了长文式铺垫？
- 是否有自然停点？
- 是否有呼吸感，而不是每句同一力度、同一密度？
- 是否适合目标平台？
- 用户要求 voice 时，是否保留作者声音？
- 是否需要交给 `$cflow-package` 做标题或 CTA？
- 是否需要交给 `$cflow-image` 做封面、插图或配图？

## 常见错误

- 把长文压缩成摘要。
- 一条里塞三个观点。
- 开头解释背景太久。
- 用户要求严谨包装时，用标题承诺但正文不兑现。
- 为了短而删掉具体细节。
- 把所有平台都写成同一种社交帖。
- 用结尾升华替代清楚判断。
