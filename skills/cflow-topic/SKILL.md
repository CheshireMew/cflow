# CFlow Topic

## 边界

只负责选题发现和选题评估。除非用户明确要求继续，否则不要写最终角度、大纲或草稿。

选题是创作者可以围绕它做内容的具体对象。它还不是主张、hook、标题或结构。

如果用户还没有可用素材、目标读者、创作目标或真实问题，只是想先聊、采访、梳理经历或补齐缺失信息，交给 `$cflow-brief`。`cflow-topic` 不承担深度采访。

## 工作流

1. 明确创作者领域、目标读者和发布目标。
2. 钉住可观察现象：读者正在经历什么、哪里和预期不一致、有什么行为或反馈信号。
3. 过滤空转词：把“有价值、影响力、个人 IP、深度、成长、系统性”等词替换成具体对象、场景或结果。
4. 从上下文中抽取选题原料：问题、决策、失败、例子、异议、反复解释的概念。
5. 按内容栏目或内容资产类型分组选题。
6. 用读者痛点、表达潜力、具体性、新鲜度、传播/转化潜力评估候选题。
7. 选出最强选题，并说明为什么值得做。
8. 当用户需要更锋利的观点时，交给 `$cflow-angle`。

## 输出

生成选题时输出：

- 内容栏目
- 选题
- 目标读者
- 读者问题
- 为什么现在值得做
- 所需素材
- 可继续加压的方向
- 下一步

评估选题时输出：

- 判断
- 最适合的用法
- 当前不够强的地方
- 修法
- 推荐角度方向

模糊输入时先输出：

- 当前清晰度：低 / 中 / 高
- 最大缺口
- 半成品选题
- 需要补的 1 到 3 个关键信息
