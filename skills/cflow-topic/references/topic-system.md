# 选题系统

## 选题来源

- 客户或读者反复问的问题
- 读者持续付出代价的错误
- 有明显取舍的个人决策
- 幕后流程
- 来自真实工作的反常识经验
- 行业内被误用的概念
- 前后对比式转变
- 失败尝试和它暴露的问题
- 创作者真实使用的清单
- 相似选择之间的比较
- 打破读者想象的幕后场景
- 来自优秀广告、脚本、杂志、故事、喜剧或其他领域的 swipe-file 模式
- 可以在标题中直接点名的受众身份
- 读者已经尝试过但失败的解决方案
- 读者在相信、购买或行动前反复提出的异议
- 可被 `$cflow-case` 扩展成案例故事的真实事件、微场景或未来预演
- 创作者正在解决的真实问题，以及已经走过一两步的路径
- 创作者明确不想回到的状态、错误生活方式或反愿景
- 创作者当前最优先研究、实践、购买、放弃或反复解释的事
- 创作者独特经历、技能、价值判断和兴趣交叉产生的具体问题

个人品牌选题不是“写我自己”。它要把创作者的路径翻译成读者也在付出代价的问题：我经历过什么、解决了什么、现在优先什么，最终都要落到读者处境、决策、痛点或行动上。

## 评分

每个维度 1 到 5 分。

- **读者痛点**：是否解决或命名了真实问题？
- **具体性**：读者能不能想象这个处境？
- **表达潜力**：这个题能不能写出强判断、强利益或强冲突？
- **新鲜度**：是否有非显而易见的区分或例子？
- **生产成本**：现有素材能不能支撑？
- **素材可放大性**：是否有具体场景、指标、前后对比、截图、轶事或强观点可放大？
- **案例潜力**：是否能找到真实、假设、类比或未来预演案例来支撑？
- **目标读者强度**：是否能对窄读者说得足够具体，让无关读者自动离开？

优先选择高痛点、高张力、高转化或高传播潜力的题。流行本身可以成为理由，只要能写出强进入点。

## 好选题五项检查

把模糊方向变成选题时，检查 5 项：

| 检查项 | 问题 | 通过标准 |
|---|---|---|
| 对象 | 到底写谁、哪件事、哪个场景？ | 有具体读者、场景或任务 |
| 目标 | 这条内容想解释、说服、教学、转化还是复盘？ | 目标类型明确 |
| 冲突 | 哪里和预期不一致？ | 能说出异常、矛盾、代价或断点 |
| 约束 | 什么不能改、必须考虑什么？ | 至少有一个真实约束 |
| 反馈 | 什么证明这个题值得继续？ | 有数据、评论、行为、案例、实验或观察入口 |

不要默认展示完整评分表。默认只告诉用户：

```text
当前清晰度：
最大缺口：
下一步：
```

## 空转词过滤

遇到模糊词时，不要直接沿用。先做替换：

- “有价值” → 对谁有用、解决什么问题、节省什么代价？
- “影响力” → 被谁看到、带来什么行为、什么指标变化？
- “个人 IP” → 想让读者记住什么、信任什么、采取什么行动？
- “深度” → 拆到哪一层、解释什么机制、反驳什么误解？
- “系统性” → 包含哪些步骤、边界、输入、输出和反馈？

如果替换不了，当前还不是选题，只是愿望或标签。

## 弱选题气味

- 只是一个大类，不是一个具体处境。
- 谁都能写。
- 没有读者决策或痛点。
- 依赖泛泛激励。
- 其实是标题，不是选题。
- 其实是角度，不是选题。
- 没有张力路径。
- 因为目标读者太宽而变泛。

## Copywork 作为选题研究

当用户想提升品味或找更原创的想法时，使用 copywork 式研究：

1. 收集目标类型或相邻类型中的优秀案例。
2. 抄写或近距离研究案例，找出可重复规则。
3. 提取选题模式、受众切片、说服动作、节奏和张力来源。
4. 把模式迁移到创作者自己的领域，不复制原表面。

好来源包括经典广告、高表现脚本、短篇故事、杂志写作、喜剧段子、高表现短内容，以及用户所在行业之外的创作者档案。
