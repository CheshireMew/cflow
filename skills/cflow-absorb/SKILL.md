# CFlow Absorb

## 工作目标

把输入材料变成可执行的 CFlow 生产规则，并在用户批准后修改对应 `SKILL.md`。

吸收的重点不是保存材料原文，而是写出可重复动作：下次遇到什么输入，先判断什么，按什么顺序处理，删掉哪类坏输出。

## 维护约束

- 正文不重复 description 已经说清的范围。
- 只保留吸收、判断、写入 skill 的规则。
- 跨 skill 调度由主入口处理；本文只处理本次机制写入哪里。
- 新规则必须短、清楚、可执行，不能把样稿全文、单篇案例或口号写进 skill。
- 修改其他 skill 时，遵守目标 skill 的文档标准：能归类就归类，只写负责的事，模板字段必须是信息单元。
- 写入前必须检查是否被单个领域、样本、作者或素材来源过拟合。

## 工作流

1. 拆材料：找出用户真正想让 CFlow 学会的动作。
2. 抽象机制：把领域、题材、人物、平台和素材来源替换成变量。
3. 判机制：判断它是否跨题材、跨任务成立。
4. 定写入点：确认应该改哪个 `skills/<name>/SKILL.md` 的哪一类规则。
5. 出计划：说明行为会怎么变，等用户批准。
6. 应用变更：修改文件并运行 `python scripts\quick_validate.py`。

## 可吸收机制

优先吸收这些：

- **判断规则**：以后遇到什么情况，先判断什么。
- **写法规则**：怎么开头、推进、收束、删减或改写。
- **质量规则**：什么算失败，命中后怎么修。
- **模板规则**：稳定的信息顺序、动作顺序或检查顺序。
- **测试用例**：能复现高频失败的用户原话或输入形态。

不要直接吸收这些：

- 单篇素材里的事实、人物、产品、数字。
- 用户个人口癖、临时偏好或单次审美判断。
- 只有一个案例支撑、说不清机制的风格模仿。
- 只能当例子、不能改变默认行为的表达。

## 拆材料

先把材料拆成小块，不要整包写入。

每个候选机制只回答五个问题：

```text
它解决什么失败？
它改变哪个生产动作？
它的底层规则是什么？
它应该写进哪个 skill？
它是否需要测试用例？
```

如果回答不出来，不升级成长期规则。

## 反过拟合检查

写入规则或资产前，先把原材料里的表面元素替换成变量。

```text
领域：论文 / 金融 / AI / 平台 / 政策 / 历史 / 个人经历
对象：某作者 / 某公司 / 某产品 / 某市场 / 某账号
来源：论文 / 图表 / 截图 / 评论 / 数据 / 访谈 / 回测
动作：对比 / 前置 / 压缩 / 删除 / 转译 / 证明 / 命名
结果：停留 / 理解 / 相信 / 收藏 / 转发 / 关注 / 转化
```

只有“动作 -> 结果”能跨变量成立，才写成通用规则。

命名规则：

```text
优先用底层动作命名：高反差证据速译。
少用领域命名：论文速译、A 股模式、AI 新闻模板。
领域只写进 use_when / avoid_when，不写成机制本身。
```

## 写入标准

写入 `SKILL.md` 时只保留能改变行为的句子。

优先改现有规则：

1. 删除误导规则。
2. 合并重复规则。
3. 收紧过宽规则。
4. 补缺失判断。
5. 最后才新增小节。

模板必须是底层结构，不是固定文案。

```text
好：事实 -> 差异 -> 动作
坏：最后加一句提醒 / 升华 / 这意味着
```

处理文风问题时，不要只写“去 AI 味”“不要套格式”。必须写清具体失败：

```text
具体失败是什么
为什么会导致失败
命中后怎么改
```

不要只列禁词，也不要依赖案例对照替代底层规则。

## 计划格式

编辑任何 skill 前，先给用户一个短计划。

```text
行为变化：
这次要写入什么机制：
涉及文件：
会删减 / 归类 / 收紧什么：
需要新增什么：
风险或不确定点：
确认后我会修改文件并跑校验。
```

计划必须具体到“下次同类任务会怎么不同”。如果说不清差异，说明还没有吸收到机制。

用户已经明确要求直接修改某个 skill 时，可以在该范围内执行。

## 应用变更

修改规则：

- 只改用户批准或明确指定的文件。
- 优先编辑 `skills/<name>/SKILL.md`。
- 不创建外部规则文件。
- 不把同一规则写到多个真源。
- 不保留旧规则的兼容说法。

修改后运行：

```powershell
python scripts\quick_validate.py
```

如果创建、删除或重命名 skill，再运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\sync_personal_skills.ps1 -PruneStale
python scripts\quick_validate.py
```
