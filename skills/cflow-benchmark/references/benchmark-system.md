# 内容对标系统

## 对标筛选

优先选择这些对标：

- 面向相近读者。
- 平台和内容形态相近。
- 内容任务相近：教育、观点、故事、转化、复盘、招募、品牌。
- 表现强且有可观察信号：阅读、互动、评论、转发、收藏、转化、持续更新。
- 能看懂结构，不只看见表面风格。
- 有可迁移模式，而不是依赖身份、资源、历史红利或不可复制事件。

不要只因为粉丝多就对标。粉丝量不是内容机制。

## 五重过滤

| 筛子 | 问题 | 淘汰信号 |
|---|---|---|
| 读者是否相近 | 对方吸引的人是不是你也想吸引的人？ | 受众完全不同 |
| 任务是否相近 | 对方内容在完成什么任务？ | 对方做娱乐，你做转化 |
| 机制是否看得懂 | 你能说清它为什么有效吗？ | 只能说“感觉好” |
| 素材是否可迁移 | 你是否有自己的事实、案例和声音承接？ | 只能复制对方经历 |
| 平台是否匹配 | 平台规则和呈现方式是否一致？ | 把短视频逻辑硬搬到长文 |

过不了五重过滤的对标，不进入深拆。

## Copywork 颗粒度

copywork 不是泛泛总结。至少拆到这些层：

- 选题：为什么是这个题，不是更大的话题？
- 读者：标题和正文分别筛选了谁？
- Hook：第一眼或前三秒用什么张力留人？
- 结构：每一段/每一镜在推进什么？
- 证据：用数据、故事、场景、对比还是权威支撑？
- 节奏：哪里快、哪里慢、哪里转折？
- 语言：哪些句子服务作者声音，哪些服务平台效率？
- CTA：下一步行动被放在什么时机？

如果只能得到“结构清晰、观点犀利、情绪到位”，说明拆得太粗。

## 迁移规则

- 学机制，不抄事实。
- 学结构，不复制人格。
- 学读者切法，不冒充身份。
- 学证据位置，不编证据。
- 学 CTA 时机，不硬套 offer。
- 学平台节奏，但保留作者声音。

迁移输出要明确交给哪个 CFlow skill：

| 学到的东西 | 交给 |
|---|---|
| 选题模式、栏目 | `$cflow-topic` |
| 核心冲突、主张 | `$cflow-angle` |
| 案例类型、故事功能 | `$cflow-case` |
| 标题、hook、封面 | `$cflow-package` |
| CTA、offer、转化桥 | `$cflow-marketing` |
| 作者表达差异 | `$cflow-voice` |
| 复用经验 | `$cflow-review` |

## 风险清单

- 对标对象只是流量大，但和目标读者不一致。
- 只抄标题，不理解正文兑现方式。
- 只抄人设，不理解内容任务。
- 把对方的私人经历当成可复制素材。
- 把平台短期红利当成内容能力。
- 对标太多，导致作者声音被磨平。
- 拆解停在评价层，没有产出可执行迁移动作。
