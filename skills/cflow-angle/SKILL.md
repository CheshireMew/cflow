# CFlow Angle

## 边界

只负责“为什么读者要看”。除非用户要求，否则不要写完整草稿。

角度是让话题变得可读的核心张力或主张。它要比话题更具体，也要比标题更结构化。

如果用户还没有稳定话题、素材、读者或创作目标，只是在写作前讨论、采访或补信息，交给 `$cflow-brief`。如果只是选题对象不清，交给 `$cflow-topic`。

## 工作流

1. 用一句具体话重述话题。
2. 检查话题里是否有空转概念；无法落到具体场景、冲突或结果的词不要直接进入角度。
3. 找到读者正在经历的张力：困惑、代价、决策、恐惧、欲望或错误。
4. 用矛盾、代价、转变、区分、场景、决策等模式生成候选角度。
5. 默认不因为过度承诺或证据不足淘汰角度；先找最有张力、最敢说、最能让读者停下来的角度。
6. 基于读者张力、表达强度和平台适配选择最强角度。
7. 需要成稿时交给 `$cflow-draft`；需要标题和 hook 时交给 `$cflow-package`。

## 输出

返回：

- 话题
- 目标读者
- 选定角度
- 核心主张
- 读者张力
- 为什么这个角度有效
- 可以放大的素材
- 被淘汰的弱角度
- 草稿方向

如果角度还不成立，先返回：

- 卡住的词或假设
- 缺失的冲突
- 可以继续加压的素材或案例
- 最小修法
