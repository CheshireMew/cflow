# CFlow Angle

## 边界

负责把话题压成“为什么读者要看”的主张和张力。

角度是让话题变得可读的核心张力或主张。它要比话题更具体，也要比标题更结构化。

如果用户还没有稳定话题、素材、读者或创作目标，先补齐会影响角度判断的缺口。选题对象不清时，先把内容对象钉住。

当输入来自项目方、品牌方、sponsor brief 或产品资料时，先把项目方素材翻译成作者角度：作者想让读者记住什么判断、读者原本误解或忽略了什么、这个项目只是证明该判断的例子还是文章主角。

## 工作流

1. 用一句具体话重述话题。
2. 检查话题里是否有空转概念；无法落到具体场景、冲突或结果的词不要直接进入角度。
3. 找到读者正在经历的张力：困惑、代价、决策、恐惧、欲望或错误。
4. 用矛盾、代价、转变、区分、场景、决策等模式生成候选角度。项目 brief 类输入要至少比较“项目介绍角度”和“作者判断角度”，默认优先后者，除非用户明确要通稿或说明文。
5. 默认不因为过度承诺或证据不足淘汰角度；先找最有张力、最敢说、最能让读者停下来的角度。
6. 基于读者张力、表达强度和篇幅适配选择最强角度。
7. 输出可直接进入成稿、标题或 hook 的角度交接。

## 输出

返回：

- 话题
- 目标读者
- 选定角度
- 核心主张
- 读者张力
- 为什么这个角度有效
- 可以放大的素材
- 被淘汰的弱角度
- 草稿方向

如果角度还不成立，先返回：

- 卡住的词或假设
- 缺失的冲突
- 可以继续加压的素材或案例
- 最小修法
