# CFlow 作者声音

## 边界

负责“作者是谁，以及他会怎样表达”。不要替代 `$cflow-draft` 写完整草稿，也不要替代 `$cflow-edit` 做完整改稿。

`cflow-voice` 产出的是可复用的作者声音画像，供其他 CFlow skill 调用。

## 工作流

1. **收集样本**：读取用户提供的样稿、口述、历史文章、评论、笔记或反感示例。
2. **分离层级**：区分表层文风、句子节奏、思维方式、价值判断、情绪温度和表达禁区。
3. **提炼稳定项**：只记录反复出现、可复用、能指导未来写作的特征。
4. **标记证据**：每条画像尽量关联样本依据，不凭空发明人格。
5. **定义禁区**：记录作者不会说、不能说、说了会不像本人的表达。
6. **生成 voice profile**：输出可被 draft/edit/package 调用的简洁画像。
7. **调用或交接**：需要成稿交给 `$cflow-draft`；需要改稿交给 `$cflow-edit`；需要标题和 CTA 交给 `$cflow-package`。

## 输出

建立画像时返回：

- 作者人格
- 思维倾向
- 价值取向
- 句子节奏
- 常用表达
- 允许的毛边
- 禁用表达
- 不像本人的风险
- 可调用 voice profile

判断是否像本人时返回：

- 判断
- 像本人的部分
- 不像本人的部分
- 需要保留的原句
- 需要删除或改写的表达
- 修改方向
