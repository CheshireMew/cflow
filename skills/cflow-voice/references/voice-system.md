# 作者声音系统

## 声音层级

不要把 voice 简化成“幽默一点”“犀利一点”。至少分五层：

1. **表层文风**：词汇、句长、口语程度、标点、段落密度。
2. **思维方式**：拆概念、讲故事、下判断、举案例、反常识、追问定义。
3. **价值判断**：默认相信什么，反感什么，站在哪类人或哪类原则一边。
4. **情绪温度**：冷静、克制、锋利、松弛、焦虑、温柔、讽刺、攻击性。
5. **灵魂倾向**：反复关心的问题、对世界的基本姿态、无法忍受的虚假。

## Voice Profile 合同

```text
作者人格：
核心关心：
默认立场：
思维动作：
句子节奏：
常用表达：
允许的毛边：
禁用表达：
不像本人的信号：
调用提醒：
```

Profile 要短而可执行。不要写成人设散文。

## 提炼规则

- 从多个样本中找重复特征，不从单句过度推断。
- 优先记录“会影响未来写作选择”的特征。
- 区分作者真实声音和平台格式造成的临时表达。
- 区分作者观点和作者表达习惯。
- 保留矛盾：一个人可以既克制又尖锐，既口语又爱拆概念。
- 不把“更像人”误判为“更多废话”。

## 样本标注

分析样稿时标注：

- 强作者句：一看就是作者会说的话。
- 弱作者句：意思对，但表达太泛。
- 外来腔：像 AI、营销号、媒体稿、鸡汤、咨询报告或平台模板。
- 灵魂句：暴露作者价值判断或世界观的句子。
- 节奏句：体现作者句长、停顿、转折方式的句子。

## 常见声音维度

### 句子节奏

- 短句密集
- 长句推进
- 爱用转折
- 爱下判断
- 爱留半句
- 爱用问题推进
- 先概念后例子
- 先场景后判断

### 思维倾向

- 拆概念
- 找根因
- 反常识
- 讲机制
- 讲亲历
- 做分类
- 追问边界
- 对比两种选择

### 情绪温度

- 克制
- 冷静
- 犀利
- 松弛
- 不耐烦
- 温柔
- 自嘲
- 带攻击性

### 价值取向

- 重视真实
- 反感空话
- 重视长期主义
- 重视行动
- 反感过度包装
- 重视边界
- 偏好慢但稳
- 偏好具体而非宏大

## 禁用表达

禁用表达要具体，不要只写“不要 AI 味”。

可记录：

- 不用哪些词
- 不用哪些句型
- 不用什么语气
- 不做什么总结
- 不说哪些正确但不像本人的话
- 不使用哪些平台套话

示例格式：

```text
禁用：值得注意的是 / 总的来说 / 赋能 / 打造 / 闭环
原因：像咨询报告或 AI 总结，不像作者本人。
替代：直接下判断，或用具体例子说。
```

## 调用规则

### 供 Draft 调用

写作前读取 voice profile。草稿应优先匹配：

- 思维动作
- 价值判断
- 句子节奏
- 允许的毛边

不要只替换几个常用词来伪装声音。

### 供 Edit 调用

改稿时对照 voice profile 判断：

- 哪些句子像作者
- 哪些只是意思正确
- 哪些太顺、太满、太像 AI
- 哪些毛边应该保留

修改应该先保留作者强句，再处理结构和清晰度。

### 供 Package 调用

标题、hook、CTA 不能脱离作者人格。

- 克制作者不要突然营销腔。
- 锋利作者不要被磨成温吞总结。
- 松弛作者不要被改成咨询报告。
- 反感鸡汤的作者不要使用励志标题。

## 更新规则

Voice profile 可以随着样本增加而更新，但要避免漂移：

- 新样本只是一次性平台表达时，不更新核心画像。
- 多次出现的新特征，加入画像。
- 与旧画像冲突时，保留证据并提示用户确认。
- 过时禁区可以删除，但必须说明为什么不再适用。
