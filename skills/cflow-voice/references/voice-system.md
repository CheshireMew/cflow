# 作者声音系统

## 共享合同

作者声音调用受 `$cflow` 的 `references/content-production-contract.md` 约束。本文件只维护 voice profile、本人味、表达禁区和不像本人的信号。通用写作纪律不在 voice 中重复维护。

## 声音层级

不要把 voice 简化成“幽默一点”“犀利一点”。至少分五层：

1. **表层文风**：词汇、句长、口语程度、标点、段落密度。
2. **思维方式**：拆概念、讲故事、下判断、举案例、反常识、追问定义。
3. **价值判断**：默认相信什么，反感什么，站在哪类人或哪类原则一边。
4. **情绪温度**：冷静、克制、锋利、松弛、焦虑、温柔、讽刺、攻击性。
5. **灵魂倾向**：反复关心的问题、对世界的基本姿态、无法忍受的虚假。

## Voice Profile 合同

```text
作者人格：
核心关心：
默认立场：
思维动作：
句子节奏：
常用表达：
允许的毛边：
禁用表达：
不像本人的信号：
调用提醒：
```

Profile 要短而可执行。不要写成人设散文。

## 提炼规则

- 从多个样本中找重复特征，不从单句过度推断。
- 优先记录“会影响未来写作选择”的特征。
- 区分作者真实声音和平台格式造成的临时表达。
- 区分作者观点和作者表达习惯。
- 保留矛盾：一个人可以既克制又尖锐，既口语又爱拆概念。
- 不把“更像人”误判为“更多废话”。
- 不把“没有 AI 味”当成目标。目标是像作者本人。
- 作者的偏见、犹豫、跳跃、重复和未完全想通的部分，只要有表达价值，就可以保留。

## 样本标注

分析样稿时标注：

- 强作者句：一看就是作者会说的话。
- 弱作者句：意思对，但表达太泛。
- 外来腔：像 AI、营销号、媒体稿、鸡汤、咨询报告或平台模板。
- 灵魂句：暴露作者价值判断或世界观的句子。
- 节奏句：体现作者句长、停顿、转折方式的句子。

## 常见声音维度

### 句子节奏

- 短句密集
- 长句推进
- 爱用转折
- 爱下判断
- 爱留半句
- 爱用问题推进
- 先概念后例子
- 先场景后判断

### 思维倾向

- 拆概念
- 找根因
- 反常识
- 讲机制
- 讲亲历
- 做分类
- 追问边界
- 对比两种选择

### 情绪温度

- 克制
- 冷静
- 犀利
- 松弛
- 不耐烦
- 温柔
- 自嘲
- 带攻击性

### 价值取向

- 重视真实

## 禁用表达

禁用表达要具体，不要只写“不要 AI 味”。

可记录：

- 不用哪些词
- 不用哪些句型
- 不用什么语气
- 不做什么总结
- 不说哪些正确但不像本人的话
- 不使用哪些平台套话

示例格式：

```text
禁用：值得注意的是 / 总的来说 / 赋能 / 打造 / 闭环
原因：像咨询报告或 AI 总结，不像作者本人。
替代：直接下判断，或用具体例子说。
```

## 中文表达反模式

这些不是通用禁词，而是提炼 voice profile 时优先检查的外来腔。只有当它们确实让文本不像作者、像 AI、营销稿或翻译稿时，才写进禁用表达。

### Trust-me 自夸句

这不是默认禁令。只有用户要求贴合作者声音、降低 AI 味或清理外来腔时，才检查文本是否在替自己证明质量。普通营销、广告和限时转化文案可以保留有功能的强承诺。

常见信号：

- “最完整”“最干净”“最详细”“最稳”
- “每一步都是真实代码”
- “不是伪代码”
- “这套方法最适合所有人”

处理方式：如果这类句子不像作者或没有转化功能，就删掉或改成可观察素材；如果它服务点击、紧迫感或 CTA，就保留并打磨。

### 翻译腔句型

中文读起来像英文直译时，要优先换成自然中文。

常见信号：

- “值得花这个复杂度” -> “这点复杂度有必要”
- “买不起这个成本” -> “这个代价太大”
- “薄封装” -> “轻封装 / 简单封装”
- “热路径” -> “高频路径 / 关键路径”

判断方法：如果一句中文几乎可以一对一回译成英文，并且中文搭配不自然，大概率是翻译腔。先换成中文母语者会自然使用的动词和名词搭配。

### Startup 黑话

除非用户所在行业真的需要，否则少用会把文本推向咨询报告或融资稿的词。

常见外来腔信号包括：

- 闭环
- 抓手
- 赋能
- 对齐
- 心智
- 赛道
- 弯道超车
- 打造

处理方式：能具体就具体。“形成闭环”通常可以写成“跑完整流程”；“占领心智”通常可以写成“让用户记住”；“赋能”通常可以写成“帮助”或“让 X 能做 Y”。

## 中文传播表达纪律

当目标是中文母语者、自然传播或短内容时，先遵守共享合同；这里只补充声音判断：

- 真实自然，专业但不端着。
- 不要被无功能的浮夸带跑。先判断强表达是作者声音、平台策略、转化策略还是无效噪音；如果它服务张力、传播或 CTA，应保留并打磨，而不是自动降温。
- 保留核心信息，让表达自然、流畅、适合传播。

## AI 味和本人味

AI 味常见信号：

- 结构过于对称，段落长度过均匀。
- 总结过满，没有真实犹豫和判断代价。
- 使用“值得注意的是、总的来说、首先其次最后、赋能、打造、闭环”等泛化词。
- 每个观点都被磨成正确废话。
- 没有具体场景、领域词、个人判断或现场反应。

但不要为了反 AI 味刻意加废话、口癖或错别字。判断标准始终是：作者本人会不会这样想、这样说、这样收尾。

## 调用规则

### 供 Draft 调用

写作前读取 voice profile。草稿应优先匹配：

- 思维动作
- 价值判断
- 句子节奏
- 允许的毛边

不要只替换几个常用词来伪装声音。

### 供 Edit 调用

改稿时对照 voice profile 判断：

- 哪些句子像作者
- 哪些只是意思正确
- 哪些太顺、太满、太像 AI
- 哪些毛边应该保留

修改应该先保留作者强句，再处理结构和清晰度。

### 供 Package 调用

标题、hook、CTA 默认优先服务内容任务、平台目标和转化目标。只有用户明确要求贴合作者声音时，voice 才作为强约束。

- 克制作者也可以在转化场景里变得更直接。
- 锋利作者不要被磨成温吞总结。
- 松弛作者也可以在限时活动里使用强 CTA。
- 反感鸡汤的作者是否使用励志标题，取决于用户目标。
- 当任务是广告、短视频、小红书、viral 或限时转化时，voice 校准不得削弱强表达。
- 当任务是渠道情报型文案时，消息感、短句、符号、内行黑话和一点粗糙感可能就是平台策略。不要为了“更像作者/更像文章”删除这些资产。

## 更新规则

Voice profile 可以随着样本增加而更新，但要避免漂移：

- 新样本只是一次性平台表达时，不更新核心画像。
- 多次出现的新特征，加入画像。
- 与旧画像冲突时，保留证据并提示用户确认。
- 过时禁区可以删除，但必须说明为什么不再适用。
