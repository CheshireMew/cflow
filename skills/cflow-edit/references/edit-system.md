# 改稿系统

## 编辑级别

- **Level 1 清理**：修清晰度、语法、节奏、冗余和小措辞。
- **Level 2 重排**：移动段落，修复转场，加强开头和结尾。
- **Level 3 重构角度**：改变角度、读者或主张，同时保留原素材。
- **Level 4 重写**：原结构无法承载目标时，用素材重写。

使用能解决真实问题的最低级别。

## 最小改动优先级

默认按这个顺序动刀：

1. 删掉假完整、空总结、泛泛铺垫。
2. 保留真实判断、强原句、具体细节和现场反应。
3. 重排素材，让主张和情绪推进更顺。
4. 局部改句，修清晰度和节奏。
5. 只有原结构无法承载目标时，才重写。

默认可以大改以增强表现力。只有用户要求保留原貌时，才避免把一篇有个人痕迹的草稿改成完美但失真的文章。

## 渠道情报型改稿

当草稿是限时入口、邀请码、注册链接、教程链接、福利活动、资格窗口、支付/出入金/工具机会时，先判断它是不是“渠道情报型转化文案”。

这类文案的有效资产：

- 消息感。
- 短句暴击。
- 利益点列表。
- 内行信息差。
- “别人还在 X，你已经 Y”的优越感。
- 粗糙但有效的紧迫感。
- 邀请码、注册链接、教程链接的直接 CTA。

改稿时默认保留这些资产，只有用户要求严谨、合规或平台风控时才处理：

- 改成完整产品介绍。
- 把短句连成长段落。
- 用正式过渡句稀释节奏。
- 把列表利益点写成说明文。
- 为了顺滑删除符号、重复和压迫感。

只修：

- 不可兑现承诺。
- 证据无法承载的绝对化表达。
- 明显诈骗感。
- 信息顺序混乱。
- CTA 不清楚。

## 诊断问题

- 唯一主张是什么？
- 读者是谁？
- 读者能得到什么？
- 哪些地方变抽象了？
- 哪些部分像作者本人？
- 哪些主张还能更硬、更具体？
- 开头是否真的换来了注意力？
- 结尾是否形成闭合？
- 每句话是否把读者带到下一句？
- 这篇是真的太长，还是只是无聊？
- 全文有没有呼吸感，还是一直同一个力度、同一种段落密度？

## 保留

- 有个人感的具体说法
- 具体例子
- 有用的不确定感
- 领域词
- 听起来像人的不均匀节奏
- 强原句

## 删除

- 泛泛激励
- 空转场
- 无功能废话
- 重复抽象名词
- 平台套话
- 机器感很强的均匀段落节奏
- “首先/其次/最后”“值得注意的是”“总的来说”“这不仅是 X 更是 Y”等 AI 式骨架

## 事实纪律

- 普通改稿、成稿和营销文案中，用户素材默认可直接使用，不主动改成“待核查”提示。
- 不把“可能不够可信、可能太营销、可能太夸张”当成默认修改理由。
- 用户要求核查、来源、合规、品牌安全或平台风控时，再进入事实纪律和承诺边界检查。
- 销售、短内容和包装场景优先改成更有冲击力、更可行动的表达，保留表现力。
- 每 500 字左右尽量保留一个具体细节、判断或现场反应，避免全文被抛光成均匀总结。

## 节奏和压缩

- 句长要有变化：短、中、长、短。
- 清晰比漂亮重要，需要清楚时优先短句。
- 一个句子承载两个想法时，优先把逗号改成句号。
- 当节奏更自然时，可以偶尔用 “And” 或 “But” 开句。
- 尽量一句一个点。
- 完成一稿后，如果感觉发胖，先删掉约三分之一。
- 如果仍然发胖，继续删重复铺垫、抽象总结和解释性喉音。
- 先自由写出来，再克制编辑。不要试图在第一稿就完美。

## 呼吸感编辑

呼吸感不是把文案改温和，而是让强表达更可读、更容易被记住。

- 如果全文都在连续加压，插入具体落点、场景、短停顿或操作句。
- 如果段落都一样长，重新切段：强句单独成段，解释句归并，列表独立出来。
- 如果每句都短，补一两句推进关系的中长句；如果每句都长，拆出短句暴击。
- 如果卖点连续堆叠，按“卖点 -> 场景/异议 -> 下一个卖点 -> CTA”重排。
- 如果观点太密，强判断后留一句例子、代价或反问，让读者有消化点。
- 如果渠道情报文案被改成长说明，恢复短句、列表、符号、停顿和直接 CTA。

## Slippery Slope 编辑

逐段问：

```text
这一句是否让下一句更容易被读下去？
```

如果不能：

- 增加张力
- 增加具体细节
- 移到后面
- 删除
- 换成能制造前进感的转场

## 编辑报告格式

```text
诊断：
编辑级别：
主要变化：
修改后草稿：
可继续加压：
```
