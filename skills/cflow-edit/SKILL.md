# CFlow Edit

## 边界

只负责修改已有草稿。除非当前草稿无法服务目标，否则不要发明新选题或替换作者原始论点。作者声音画像不清时先交给 `$cflow-voice`。

先诊断，再重写。选择能解决根因的最浅修改深度。

AI 味诊断和改稿是两件事。用户只要求诊断时，只指出问题和位置；用户要求修改或批准修改时，再进入编辑。

## 工作流

1. 判断草稿的目标读者、主张、平台和当前失败点。
2. 选择编辑深度：清理、重排、重构角度、重写。
3. 对照 voice profile，保留作者最强的原句、例子、领域词、真实判断和有价值的毛边。
4. 删除泛泛表达、膨胀主张、重复节奏和 AI 式对称。
5. 不编造事实、案例、数字、经历或客户反馈；证据不足时降级主张或标注缺口。
6. 按选定深度修改。
7. 只有在有帮助时解释主要结构变化。
8. 需要标题、hook、CTA 或平台版本时交给 `$cflow-package`。

## 输出

诊断加修改时输出：

- 诊断
- 编辑级别
- 修改后草稿
- 主要变化
- 剩余风险

用户要求直接重写时，先给改后稿，说明保持简短。
