# CFlow Asset

## 边界

负责从非写作任务导向的个人材料中提取信息资产。典型输入是旧笔记、日记、manifest 导出、复盘记录、摘录合集、长期素材库、混合想法和个人知识碎片。

`cflow-asset` 不写文章、不生成选题池、不做成稿前采访、不替代 `$cflow-brief` 追问写作缺口、不替代 `$cflow-voice` 更新作者声音画像、不替代 `$cflow-account` 做账号诊断、不替代 `$cflow-maintain` 修改 skill 规则。

默认只输出信息资产提取报告。用户明确要求“保存、沉淀、写入、建档、落文件、创建资产库”时，才可以创建或更新 `profiles/` 下的个人运行资产文件。禁止直接修改 `skills/`、`SKILL.md`、`references/` 或 agent metadata；如果提取过程发现 CFlow 规则缺陷，输出维护建议并交给 `$cflow-maintain`。

## 适用输入

- 个人旧笔记、日记、manifest、知识库导出。
- 混合了观点、情绪、链接、摘录、prompt、交易复盘、商业想法和生活记录的长材料。
- 用户问“这些笔记里有什么有用信息”“这些记录体现了我什么倾向”“帮我把旧笔记资产化”。
- 用户不要求马上写文章，只想沉淀判断系统、个人原则、风险清单或开放问题。

## 不适用输入

- 用户正在准备一篇文章、脚本、营销稿或发布内容，且需要采访、追问、补缺口：交给 `$cflow-brief`。
- 用户要生成选题、栏目或内容计划：交给 `$cflow-topic`。
- 用户要提炼作者声音、表达禁区或写入唯一 voice profile：交给 `$cflow-voice`。
- 用户要诊断账号定位、主页、栏目、数据和转化路径：交给 `$cflow-account`。
- 用户要修改 CFlow skill 本身：交给 `$cflow-maintain`。

## 工作流

1. **判断任务目标**：确认用户是要信息资产提取，而不是写作前 brief、选题、账号诊断或作者画像更新。
2. **拆分复合材料**：把输入拆成观点、原则、风险、决策、商业资产、事实资料、外部摘录、作者声音线索、生活记录、prompt/工具片段和噪音。
3. **提取可复用资产**：只沉淀未来能调用的信息，不把孤立金句、单次情绪和未核查事实伪装成原则。
4. **分层归档建议**：按个人原则、决策框架、风险清单、业务资产、内容资产、开放问题、待核查事实和拒绝沉淀分层。
5. **专项 handoff**：作者声音交给 `$cflow-voice`，账号系统交给 `$cflow-account`，转化路径交给 `$cflow-marketing`，选题交给 `$cflow-topic`，事实核查交给 `$cflow-research`，规则缺陷交给 `$cflow-maintain`。
6. **保存闸门**：只有用户明确要求写入时，才创建或更新 `profiles/` 下的资产文件；保存前说明文件方案，避免覆盖既有运行资产。

## 资产分层

提取时优先分成：

```text
个人原则：
决策框架：
风险清单：
商业资产：
内容资产：
作者声音线索：
开放问题：
待核查事实：
拒绝沉淀：
专项 handoff：
```

- **个人原则**：跨场景约束行为的长期判断。
- **决策框架**：以后做选择时可重复调用的问题、步骤或检查清单。
- **风险清单**：反复伤害用户判断、行动、现金流、健康或关系的模式。
- **商业资产**：产品、渠道、收入来源、CTA、社群、客户、私有链接或变现路径。
- **内容资产**：可复用的内容机制、案例、栏目素材、表达资产或生产模式。
- **作者声音线索**：价值判断、表达禁区、句子节奏、情绪温度和灵魂倾向；需要持久化时交给 `$cflow-voice`。
- **开放问题**：材料暴露但尚未验证的问题。
- **待核查事实**：外部数据、链接、引用、人物、产品或平台规则。
- **拒绝沉淀**：单次情绪、身体状态、孤立链接、无上下文金句、命令片段或没有用户判断的外部摘录。

## 输出

默认输出：

- 当前判断
- 有用信息分层
- 可沉淀资产
- 不应沉淀内容
- 专项 handoff
- 建议保存结构
- 下一步最小动作

用户要求写入时输出并执行：

- 文件方案
- 写入范围
- 不写入范围
- 创建或更新的 `profiles/` 文件
- 后续需要交给哪个 skill
