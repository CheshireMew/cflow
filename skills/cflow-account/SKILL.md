# CFlow Account

## 边界

负责诊断用户自己的内容账号、主页、栏目组合、内容样本、发布节奏、互动反馈、表现数据和转化路径。账号诊断的交付物是根因判断、证据分级、优先级和下一步行动，不是直接写完整内容。

账号诊断不是对标拆解。找可模仿账号、拆别人账号、分析爆款结构或做 copywork 时，交给 `$cflow-benchmark`。复盘单篇内容、已发布内容库或发布结果时，交给 `$cflow-review`。设计 offer、CTA 和完整转化路径时，交给 `$cflow-marketing`。

默认可以基于用户提供的账号描述、截图转述、主页文案、内容样本、后台数据、评论或创作者体感做诊断。没有数据时可以做低证据诊断，但必须标注假设性质和需要补充的信息；不得假装知道平台分发、真实受众或隐藏指标。

只有用户要求查看当前账号页面、实时竞品、平台趋势、公开数据或来源核查时，资料搜集交给 `$cflow-research`。用户只提供离线材料时，不主动联网。

## 工作流

1. 判断诊断对象：主页、账号定位、内容栏目、单个平台账号、多平台账号、数据表现、商业化路径或生产系统。
2. 盘点输入证据：账号目标、目标读者、主页信息、内容样本、栏目、发布节奏、指标、评论反馈、转化动作和创作者体感。
3. 标注证据等级：有原文、有截图、有数据、有评论、只有描述、只有体感；缺什么就写清楚。
4. 明确账号任务：增长、建立信任、筛选客户、教育市场、销售转化、社群运营、个人品牌、作品集展示或内容实验。
5. 做账号级根因诊断：定位、目标读者、主页承诺、栏目组合、选题质量、角度强度、包装、内容结构、发布节奏、互动反馈、转化路径和生产系统。
6. 如果有数据，先统一口径，再判断 reach、engagement、retention、conversion、trust 和生产成本；不同平台、不同时间窗口、不同内容目标不可直接横比。
7. 如果没有数据，基于内容本体和账号结构提出候选假设，不下确定性表现结论。
8. 收口到少数关键问题：区分主因、次因、证据不足的假设和不该现在处理的噪音。
9. 给出优先级建议：先修能改变账号理解、内容供给或转化路径的动作，再修局部文案和细节。
10. 需要专项执行时，交给对应 CFlow skill，而不是在账号诊断里硬做所有产物。

## 输出

返回：

- 账号诊断对象
- 已有证据
- 缺失信息
- 证据等级
- 账号当前任务
- 账号级根因
- 内容供给问题
- 主页和定位问题
- 数据或反馈解释
- 转化路径问题
- 生产系统问题
- 优先级建议
- 30 天实验方向
- 需要交给哪个 CFlow skill

无数据或弱数据时必须输出：

- 当前判断性质：低证据诊断 / 候选假设 / 基于用户材料
- 不能确认的部分
- 最值得补充的 1 到 3 个信息
