# 账号诊断系统

## 诊断入口

先判断用户给来的是什么，不要默认进入数据分析。

| 输入 | 主问题 |
|---|---|
| 账号主页、简介、置顶内容 | 陌生人是否能理解这个账号为谁解决什么问题 |
| 多篇内容样本 | 内容供给是否稳定，栏目和读者任务是否清楚 |
| 后台数据、截图、表格 | 表现问题更像分发、互动、留存、转化还是生产成本 |
| 评论、私信、用户反馈 | 受众是否准确，读者到底在追问什么 |
| 创作者体感 | 生产系统哪里卡住，是否有定位或栏目错配 |
| 无数据描述 | 只能做结构诊断和候选假设，不能断言真实表现 |

用户只说“帮我看看账号”时，先根据已有材料推进低证据诊断，不要把流程卡死在追问里；但必须说明哪些判断需要补证据。

## 证据分级

账号诊断必须区分证据强弱。

| 等级 | 证据 | 可做判断 |
|---|---|---|
| A | 原文、主页截图、内容样本、指标、评论齐全 | 可以做账号级根因诊断和优先级排序 |
| B | 有内容样本和部分指标 | 可以判断内容机制和表现假设 |
| C | 有主页或内容样本，无指标 | 可以判断定位、栏目、包装和内容本体 |
| D | 只有用户描述或体感 | 只能输出候选假设和补充清单 |

低证据诊断也要有用，但不要把“可能”写成“已经证明”。

## 账号任务

账号不是天然为了涨粉。先确认它现在承担什么任务：

- **Reach**：让更多陌生人看见。
- **Trust**：建立专业、审美、判断或人格信任。
- **Engagement**：让读者评论、收藏、转发、私信或参与讨论。
- **Conversion**：让读者预约、购买、进群、留资、咨询或订阅。
- **Learning**：通过发布测试选题、受众、表达和 offer。
- **Portfolio**：展示作品、案例、方法和可信度。
- **Community**：维系社群关系、回答问题、推动互动。

同一个账号可以有多个任务，但诊断时要先找当前主任务。用涨粉指标评估高意向转化账号，或者用转化指标评估早期定位探索账号，都会误诊。

## 根因地图

账号问题优先按账号级根因收口，而不是按单条内容现象修补。

### 定位和主页

常见问题：

- 陌生人看不出账号为谁服务。
- 主页承诺太抽象，只说身份、价值观或宏大领域。
- 账号名称、简介、置顶内容和真实发布内容互相不支持。
- 主页只表达创作者想说什么，没有表达读者为什么要关注。
- CTA 太早或太重，账号还没有铺出足够信任。

### 个人资料第一印象

账号主页是陌生人判断是否信任、关注或继续了解的第一层证据。诊断主页时，不只看简介是否顺口，也要看个人资料里的每个元素是否共同支持一个清楚的关注理由。

检查维度：

- **定位标签**：账号是否快速说明自己是谁、为谁提供什么、凭什么值得关注。标签要帮助读者理解关注理由，不只是堆身份。
- **视觉一致性**：头像、头图、配色、内容配图和产品视觉是否形成识别感。视觉一致性服务专业感和记忆点，不等于必须使用亮色或复杂设计。
- **品牌符号**：emoji、符号、固定称呼、口头标记或视觉锚点是否强化识别。符号只有在反复出现并服务账号记忆时才有价值，不能为了装饰而加。
- **简介可信度**：简介是否用真实角色、经历、作品、成果、失败经验、客户对象或项目经验支撑可信度。成就、履历、结果、身份和项目经验必须来自用户素材，不得为了增强合法性编造。
- **置顶内容**：置顶内容是否承担作品证明、可信度、个人故事、核心主张、代表作或转化承接，而不是随意置顶高互动内容。

如果个人资料第一印象弱，先判断根因：看不懂定位、缺少视觉识别、缺少可信度证据、置顶内容不承接主页承诺，还是 CTA 与当前信任程度不匹配。不要直接建议“换头像”“加 emoji”或“重写简介”。

执行分流：

| 发现 | 交给 |
|---|---|
| 头像、头图、配色、视觉锚点不统一 | `$cflow-image` |
| 简介、置顶内容、主页文案表达弱 | `$cflow-package`、`$cflow-edit` |
| 缺少可信度素材、作品证明或个人故事 | `$cflow-brief`、`$cflow-case` |
| 主页承诺和 offer / CTA 承接弱 | `$cflow-marketing` |

检查问题：

```text
目标读者是谁：
他们来这里想解决什么问题：
主页承诺了什么：
最近内容是否持续兑现这个承诺：
关注理由是否能在 5 秒内看懂：
下一步动作是否自然：
视觉和符号是否形成识别感：
简介和置顶内容是否提供可信度证据：
```

### 内容供给

常见问题：

- 栏目太散，读者不知道关注后会持续得到什么。
- 选题只从创作者想表达的概念出发，不从读者处境出发。
- 同一账号里混杂多个不兼容读者任务。
- 内容有观点但没有案例、场景或证据。
- 内容单条看还行，组合起来没有账号记忆点。
- 发布节奏看似勤奋，但没有稳定栏目和复用机制。

检查栏目时，不要只数主题标签。要看每个栏目服务哪个读者任务、是否能重复生产、是否有足够素材来源、是否支撑账号主任务。

### 包装和首屏

常见问题：

- 标题、封面、开头没有筛选目标读者。
- Hook 承诺和正文兑现错位。
- 账号主页强，单条内容第一眼弱。
- 内容本体有价值，但包装没有显示具体收益、冲突、场景或身份表达。

包装问题交给 `$cflow-package` 或 `$cflow-image` 执行，不在账号诊断里批量生成标题和封面。

### 数据和反馈

数据先按目标解释：

| 信号 | 可能问题 |
|---|---|
| 低 reach、强私信或转化 | 包装或分发弱，但题和人群可能窄而有价值 |
| 高 reach、低关注 | 单条内容吸引泛人群，账号承诺或主页接不住 |
| 高收藏、低评论 | 有用但不够可讨论，可能缺观点压力或互动入口 |
| 高评论、低转化 | 讨论强，但 offer、信任或行动路径不足 |
| 高完读或高停留、低行动 | 内容有吸引力，但 desire、proof 或 CTA 不够 |
| 强互动来自非目标人群 | 选题或包装筛错人 |
| 同栏目波动大 | 角度、包装、发布时间或样本太少，不能直接下结论 |

不同平台、不同时间窗口、不同内容目标不可直接横比。可以比较相对排名、趋势、异常值和同栏目样本，不要用总点赞替代账号健康度。

### 转化路径

内容账号服务商业目标时，检查：

```text
账号吸引谁：
内容建立什么信任：
读者下一步动作是什么：
主页、置顶、私信、链接或评论是否承接：
offer 是否清楚：
行动摩擦是否匹配信任程度：
```

如果 offer、CTA 或 funnel stage 不清，交给 `$cflow-marketing`。如果只是主页简介或置顶文案需要改写，交给 `$cflow-package` 或 `$cflow-edit`。

### 生产系统

账号长期不起色不一定是单条内容差，也可能是生产系统问题：

- 没有稳定选题来源。
- 没有栏目复用结构。
- 每条都从零开始，生产成本过高。
- 缺少复盘循环，发布后没有把评论和数据变成下一轮素材。
- 对标过多导致声音、读者和栏目漂移。
- 创作者擅长的素材形态和选择的平台不匹配。

生产系统建议要落到下一步动作，例如建立栏目、复用结构、降低发布成本、集中测试一个读者任务或停止低质量泛发。

## 优先级排序

账号诊断必须给优先级，不输出平均用力的建议清单。

按这个顺序排序：

1. **理解问题**：陌生人看不懂账号为谁服务，先修主页、定位和栏目承诺。
2. **供给问题**：内容持续性差、栏目散、读者任务混乱，先修内容组合。
3. **选题和角度问题**：读者处境弱、主张平，交给 `$cflow-topic` 和 `$cflow-angle`。
4. **包装问题**：内容成立但第一眼弱，交给 `$cflow-package` 或 `$cflow-image`。
5. **信任和证据问题**：观点多但案例少，交给 `$cflow-case`、`$cflow-draft` 或 `$cflow-edit`。
6. **转化问题**：有注意力但没有行动，交给 `$cflow-marketing`。
7. **生产问题**：成本高、不可持续，调整栏目、模板和复盘循环。

如果定位和栏目不清，不要先建议日更、改封面、追热点或换平台。局部优化不能替代账号级理解。

## 30 天实验

账号诊断建议要能进入实验，不只写原则。

一个 30 天实验至少包含：

```text
主假设：
目标读者：
要测试的栏目：
内容数量：
每条内容的共同约束：
要观察的指标：
要收集的评论或私信信号：
停止条件：
下一次复盘时间：
```

没有数据时，30 天实验用于补证据；有数据时，30 天实验用于验证根因修法。

## 协作路由

账号诊断只负责判断和排序。执行时交给专项 skill：

| 诊断发现 | 交给 |
|---|---|
| 目标读者和栏目不清 | `$cflow-brief`、`$cflow-topic` |
| 选题泛、没有读者处境 | `$cflow-topic` |
| 观点平、没有张力 | `$cflow-angle` |
| 内容样本结构散 | `$cflow-edit`、`$cflow-draft` |
| 缺案例、缺证据、太抽象 | `$cflow-case` |
| 短内容链路弱 | `$cflow-shortform` |
| 标题、开头、主页表达弱 | `$cflow-package` |
| 封面、头图、视觉识别弱 | `$cflow-image` |
| 分享、转发、评论入口弱 | `$cflow-viral` |
| offer、CTA、私信或购买路径弱 | `$cflow-marketing` |
| 需要找对标 | `$cflow-benchmark` |
| 需要复盘已发布内容库 | `$cflow-review` |
| 需要查当前账号或竞品事实 | `$cflow-research` |
