# CFlow Image

## 边界

负责内容的视觉资产：封面、插图、配图、文章头图、分享图、thumbnail text、cover text、视觉 brief 和图片生成 prompt。

只有用户要求真实来源、事实核查、合规、品牌安全或发布限制时，才把图片里的事实、界面、人物、产品状态或数据交给 `$cflow-research`；普通视觉包装先服务点击、停留、理解和传播。

视觉资产必须服务内容主张，不做只好看的装饰图。系列内容、账号栏目或重复出现的内容形态，要优先考虑视觉识别和可复用视觉语法，而不是每次重新做一张孤立封面。

## 工作流

1. **判断图像任务**：封面、文章头图、正文插图、分享图、图表/示意图、截图说明、视觉 prompt 或视觉对标。
2. **确认内容基础**：读者、篇幅、交付形态、发布约束、核心主张、读者张力和第一眼动作。
3. **选择图像类型**：真实照片、产品截图、生成图、图表、流程图、信息图、文字型封面或混合方案。
4. **设计第一眼信息层级**：主视觉、主文字、辅助文字、品牌/作者信息和场景信号。
5. **判断系列识别**：如果内容属于固定栏目、系列、账号资产或可重复发布形态，定义可复用的版式、色彩、字体层级、截图处理、编号或视觉锚点。
6. **检查必要性**：插图是否帮助理解、记忆、点击、转化或传播；不能帮助就不加。
7. **生成视觉 brief**：比例、主题、构图、文字、风格、素材来源、用户要求出现和用户要求避开的元素。
8. **设计视觉实验**：需要测试第一眼表现时，给出 1 到 3 个可比较变量，并说明发布后交给 `$cflow-review` 看什么信号。
9. **生成图片 prompt**：需要 AI 生成图时，给出可执行 prompt；用户要求真实来源或发布限制时，再说明事实边界和不能伪造的部分。
10. **交接**：标题/hook/CTA 交给 `$cflow-package`；用户要求事实来源时交给 `$cflow-research`；对标来源交给 `$cflow-benchmark`；发布后表现交给 `$cflow-review`。

## 输出

封面或分享图输出：

- 比例和发布约束
- 第一眼目标
- 主视觉方向
- 封面文字或 thumbnail text
- 构图说明
- 风格和颜色方向
- 系列识别规则
- 用户要求出现的元素
- 用户要求避开的元素
- 视觉实验变量
- 图片生成 prompt 或制作 brief

插图或配图输出：

- 插图目的
- 放置位置
- 图像类型
- 解释什么信息
- 是否需要真实来源（仅用户要求时）
- 插图 brief 或 prompt
- 不建议加图的理由

视觉对标输出：

- 可学习的视觉机制
- 不可复制的元素
- 可迁移到本内容的构图或信息层级
- 交接到哪个 CFlow skill
