# CFlow Image

## 边界

负责内容的视觉资产：封面、插图、配图、文章头图、社交图、thumbnail text、cover text、视觉 brief 和图片生成 prompt。

不要替代 `$cflow-package` 做普通标题、hook、opening、caption、CTA 或平台文本版本；不要替代 `$cflow-draft` 写正文；不要替代 `$cflow-benchmark` 做完整对标拆解；不要替代 `$cflow-research` 查事实来源。图片里承载的事实、界面、人物、产品状态或数据可疑时，先交给 `$cflow-research`。

视觉资产必须服务内容主张，不做只好看的装饰图。

## 工作流

1. **判断图像任务**：封面、文章头图、正文插图、社交配图、图表/示意图、截图说明、视觉 prompt 或视觉对标。
2. **确认内容基础**：读者、平台、格式、核心主张、读者张力、证据和作者声音。
3. **选择图像类型**：真实照片、产品截图、生成图、图表、流程图、信息图、文字型封面或混合方案。
4. **设计第一眼信息层级**：主视觉、主文字、辅助文字、品牌/作者信息、证据或场景信号。
5. **检查必要性**：插图是否帮助理解、记忆、点击或信任；不能帮助就不加。
6. **生成视觉 brief**：平台比例、主题、构图、文字、风格、素材来源、必须出现和必须避免的元素。
7. **生成图片 prompt**：需要 AI 生成图时，给出可执行 prompt，并说明事实边界和不能伪造的部分。
8. **交接**：标题/hook/CTA 交给 `$cflow-package`；事实来源交给 `$cflow-research`；对标来源交给 `$cflow-benchmark`；发布后表现交给 `$cflow-review`。

## 输出

封面或社交图输出：

- 平台和比例
- 第一眼目标
- 主视觉方向
- 封面文字或 thumbnail text
- 构图说明
- 风格和颜色方向
- 必须出现的元素
- 必须避免的元素
- 图片生成 prompt 或制作 brief

插图或配图输出：

- 插图目的
- 放置位置
- 图像类型
- 解释什么信息
- 是否需要真实来源
- 插图 brief 或 prompt
- 不建议加图的理由

视觉对标输出：

- 可学习的视觉机制
- 不可复制的元素
- 可迁移到本内容的构图或信息层级
- 交接到哪个 CFlow skill
